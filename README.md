# AI, Machine Learning & Deep Learning Projects

Welcome to my AI Projects repository! This repository contains a collection of projects completed during my learning journey in Artificial Intelligence, Machine Learning, and Deep Learning. Each project focuses on solving real-world problems while applying data analysis, model development, and modern AI techniques.

## Repository Structure

* **Supervised Learning** – Classification and regression projects using popular machine learning algorithms.
* **Unsupervised Learning** – Clustering, dimensionality reduction, and pattern discovery projects.
* **Deep Learning Projects** – Neural network, CNN, and computer vision projects built with deep learning frameworks.

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* TensorFlow / Keras
* OpenCV
* Jupyter Notebook

## Objectives

* Build practical AI and machine learning solutions.
* Explore different algorithms and compare their performance.
* Strengthen problem-solving and data analysis skills.
* Continuously add new projects as I learn more advanced concepts.

## Note

Datasets, large model files, and other unnecessary files are excluded from this repository using `.gitignore` to keep the repository lightweight and organized.
